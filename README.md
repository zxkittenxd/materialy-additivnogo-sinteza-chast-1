# Материалы аддитивного синтеза — часть 1 (тест)

Одностраничный интерактивный тест: 120 вопросов (одиночный и множественный выбор, 5 вопросов с рисунками)
по файлу «ТЕСТЫ_ККР_Материалы_аддитивного_синтеза_часть_1.docx». Правильные ответы — из жёлтых выделений исходного docx.

- Режимы: проверка по вопросу / проверка в конце
- Перемешивание вопросов и вариантов, ключи, частичный зачёт (0,5 балла), 10-балльная шкала
- Без сборки и зависимостей: один `index.html`

## Демо

https://zxkittenxd.github.io/materialy-additivnogo-sinteza-chast-1/

## Как обновить

1. Отредактируйте `index.html` (массив `DATA` в конце файла).
2. `git add -A && git commit -m "update" && git push` — через 1–2 минуты сайт обновится.
